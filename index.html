How to interpret the results

CT = completion time. TAT = CT − AT. WT = TAT − BT. RT = first start − AT.

FCFS and SJN run a selected process to completion. SJN chooses the shortest burst among arrived processes. RR runs each process for at most one quantum, then rejoins it to the ready queue if needed.

Ties use arrival time, then input order. In RR, arrivals at a slice boundary enter the queue before the interrupted process rejoins it.

Model: one CPU, one known CPU burst per process, no I/O or priorities, and zero context switch cost. Utilization includes idle time from time 0. Handoffs count only a change between two different processes without an idle gap.
